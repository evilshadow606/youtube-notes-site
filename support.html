YouTube Notes Support

Quick fixes for installation, the on-page panel, notes, timestamps, copying, and exports.

Panel Notes Timestamps Copy & export Navigation Report a bug

The panel does not appear

  1. Confirm you are on a standard https://www.youtube.com/watch?v=... video page.
  2. Refresh the YouTube tab after installing or reloading the extension.
  3. Open the extension popup and select Open Notes.
  4. Look for the small dark N restore button near the lower-right edge.
  5. Check the extension card at chrome://extensions for reported errors.

Open Notes from the popup

On a supported video page, the popup shows the current note count. Select Open Notes to restore, reveal, and focus the full panel. If the popup asks you to refresh, refresh the video page once.

Restore a minimized panel

Select the small N button on the YouTube page, or use Open Notes in the extension popup. Restoring updates the saved panel preference.

Notes are not saving

  • Make sure the note contains non-whitespace text.
  • Wait for the video player to finish loading before opening the composer.
  • Do not navigate to another video before saving.
  • Reload the extension and refresh the YouTube tab if the problem persists.

A failed save should leave your composer text available so you can try again.

Timestamps do not seek correctly

Confirm the video player is available and the page is still showing the video associated with the note. Browser autoplay policy may prevent playback from starting, but seeking should still occur. Refresh the page if YouTube’s player is unresponsive.

Search does not show an expected note

Search applies only to notes for the current video. Clear the search field or press Escape while it is focused to restore the full current-video list. Search does not look across other videos.

Copy to clipboard fails

Keep the YouTube tab active and try again. Chrome, the operating system, or an organization policy may block clipboard access. The extension reports the failure without changing your note.

An export does not download

  • Confirm the current video has at least one saved note.
  • Check Chrome’s download indicator and configured download folder.
  • Check whether your browser or organization blocks downloads.

Exports include all notes for the current video even when search is active.

YouTube navigation shows the wrong state

YouTube often changes videos without a full page reload. YouTube Notes listens for this navigation and reloads the correct note list. If the page appears stale, refresh the tab. Your minimized preference continues across video navigation.

Reload the extension

  1. Open chrome://extensions.
  2. Find YouTube Notes and select its reload button.
  3. Refresh every open YouTube tab.

Reinstall only as a last resort

Uninstalling may remove locally stored notes. Export important notes before reinstalling. Try reloading the extension and refreshing YouTube first.

Report a bug

Users will be able to report issues through the project’s GitHub repository once the public repository and support link are available.
